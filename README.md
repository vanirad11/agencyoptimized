# NorthPeak Digital

Responsive one-page agency website built with vanilla HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This is a static site and can be deployed to Netlify, Vercel, or GitHub Pages with no build step. Upload the three files (`index.html`, `styles.css`, `script.js`) and this README.
